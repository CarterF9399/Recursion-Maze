This Recursion Maze Assignment was a part of my COSC 1P03 course and used many different object-oriented programming concepts such as enums, classes, etc. This project uses an input file (one of the maze .txt files) and reads it, puts it into an array, and then uses a maze solving algorithm to solve the maze and prints out a visualization of the solved maze to the console.
Note: This course used a local "Brock" package that had certain methods to replace typical Java methods for simplicity in the first-year course. Many of these methods can also be changed to use actual Java classes.

This project was made using the IntelliJ IDE.
